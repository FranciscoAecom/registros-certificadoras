# Issued Credits Standards

Este diretório foi reservado para a futura coleta e padronização dos dados de créditos emitidos por standard.

Estrutura prevista:
- `shared/bronze`: utilitários compartilhados de extração bruta
- `shared/silver`: padronização determinística e rastreável
- `shared/gold`: consolidação analítica
- `shared/reference`: referências operacionais específicas dessa frente
